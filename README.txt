BCPG MedQuest BD — Mobile Web Prototype

How to use on Android:
1. Download and extract this ZIP using your phone's Files app.
2. Open the BCPG_MedQuest_BD folder.
3. Tap index.html and choose Chrome (or another browser).
4. You can use the app-like quiz interface in the browser.

Included:
- Biology, Physics, Chemistry, General GK, Current Affairs, English and Mental Ability sections
- Multiple-choice questions with answer explanations
- Mixed 5-question mini test
- Bookmarks and local progress saved in the browser on that device

Important:
- This is a web prototype, not an Android APK/AAB and not published on Google Play.
- Progress is saved only in the browser on the same device.
- The questions are starter examples. Current Affairs currently has sample questions about how to verify current information, not a live/current news feed. Add date-stamped, verified current-affairs MCQs before public release.
- For Play Store publication, this prototype needs an Android packaging/build process, app icon, privacy policy, testing and a signed release bundle.
